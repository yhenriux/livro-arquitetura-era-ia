# Arquitetura da Informação para Produtos com IA

[Yago Henrique Andrade Almeida](autor.md)

Proposta editorial em avaliação. O livro apresenta fundamentos e métodos da Arquitetura da Informação para projetar produtos e sistemas com IA. O caso fictício da Biblioteca Ipê reúne catálogo, portal e atendimento para explorar organização do conhecimento, linguagem, navegação, conteúdo, busca, avaliação e governança.
